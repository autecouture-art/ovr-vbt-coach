# フォーム動画撮影 MVP 計画

## 目的

セッション中に VBT 計測を続けながら、フォーム確認用の動画を撮れるようにする。動画は後でセット履歴と見比べられることを優先し、AI解析は後段に分ける。

## 現状

- `enable_video_recording` 設定と iOS の Camera / Microphone / Photo Library usage description はある。
- `expo-camera` を追加済み。
- `form_video_records` テーブルと `VideoRecordingService` を追加済み。
- 録画画面は `app/form-video-recorder.tsx` としてセッション画面から分離済み。
- セッション中は BLE / HealthKit / SQLite 保存 / 音声が同時に動くため、最初から重い動画解析は入れない。

## MVP

1. 設定で `フォーム動画モード` をONにする。
2. セッション画面に `録画` ボタンを表示する。
3. 録画画面はフルスクリーンで、開始 / 停止 / 破棄 / 保存だけにする。
4. 保存時に以下のメタ情報を一緒に持つ。
   - session_id
   - lift
   - set_index
   - load_kg
   - started_at
   - ended_at
   - local_uri
5. セッション履歴カードに関連動画数を表示する。
6. セット詳細から関連動画を開けるようにする。

## 実装済み

- `expo-camera` 追加。
- `app/form-video-recorder.tsx` 追加。
  - カメラ/マイク権限確認。
  - カメラプレビュー。
  - 録画開始 / 停止 / 破棄 / 保存。
  - シミュレーターやカメラ利用不可時のエラー表示。
- `VideoRecordingService` 追加。
  - 一時録画URIを `documentDirectory/form-videos/` にコピーして永続化。
  - セッション/種目/セット/重量/開始終了時刻/再生URIをSQLiteへ保存。
- `DatabaseService` に `form_video_records` テーブルと取得/保存/削除APIを追加。
- セッション画面に `フォーム録画` ボタンを追加。
- セッション履歴カードに動画件数チップを追加。
- セット詳細に動画一覧を追加。
  - 動画を開く。
  - 共有する。
  - セットとの紐付けを解除する。
- Codex Export に `form_videos` を追加。

## 実装順

1. `expo-camera` を Expo SDK 54 対応バージョンで追加する。
2. `VideoRecordingService` を作り、録画メタデータだけを SQLite に保存する。
3. セッション画面に設定ON時だけ録画ボタンを出す。
4. 録画中はセッション計測画面の再描画負荷を増やさないよう、カメラ画面を別コンポーネントに隔離する。
5. 動画ファイルは端末ローカル保存を基本にし、外部共有やクラウド同期は別フェーズにする。

## 注意点

- iOS は他アプリやバックグラウンドでの自由な録画を許可しないため、録画中はアプリ内カメラ画面を開く設計にする。
- 動画撮影中に HealthKit 心拍や BLE 入力が途切れる可能性があるため、最初の実機テストでは VBT 計測と動画を同時に動かして確認する。
- 動画解析や姿勢推定は重いので、まずは「撮れる・保存できる・セットと紐付く」までを合格条件にする。
